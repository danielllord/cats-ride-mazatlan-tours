# Mazatlán Smiles

Build a complete, production-ready, responsive website for:

CAT’S RIDE MAZATLAN
Private personalized tours in Mazatlán, Sinaloa, Mexico

IMPORTANT DESIGN INSTRUCTION:
I am attaching:
1. A finished website mockup
2. An official Cat’s Ride Mazatlan logo
3. A photograph of Martin, the tour guide

Use the attached website mockup as the PRIMARY visual reference.

Recreate the overall appearance, layout, proportions, section order, visual hierarchy, colors, spacing, tropical Mazatlán aesthetic, typography feel, buttons, cards, and content organization as closely as practical in a real responsive website.

Do NOT redesign this as a generic travel website.

Use the supplied Cat’s Ride Mazatlan logo as the actual website logo.

Use the supplied photo of Martin in the "Meet Martin" / welcome section. Do not generate or substitute another person.

The website should feel:
- Professional
- Friendly
- Local
- Tropical
- Trustworthy
- Personal rather than corporate
- Easy for cruise passengers and tourists to use from a phone

BRAND STYLE

Primary colors:
- Deep navy blue
- Ocean blue / turquoise
- Golden yellow / sunset orange
- White

Use tropical imagery and Mazatlán-inspired styling without making the site cluttered.

Use:
- Rounded cards
- Large photography
- Strong CTA buttons
- Clean modern body fonts
- A tasteful handwritten/script font for selected headings such as "Explore Mazatlán" or accent text

Make accessibility and readability a priority.

Mobile:

RESPONSIVE DESIGN

The site must work especially well on phones because many customers will be travelers or cruise passengers.

For mobile:
- No horizontal scrolling
- Large tap targets
- Easy-to-read text
- Full-width booking form
- Sticky or easily accessible booking CTA
- Compress and optimize images
- Stack cards cleanly
- Keep Martin’s image prominent
